# react-smart-copy starter

A copy field, `useCopy` with your own button and its announcement, and a table pasted from
Excel or Google Sheets. [Open it in StackBlitz](https://stackblitz.com/github/suprabhat02/react-smart-copy/tree/main/examples/starter?file=src%2FApp.tsx), or run it here:

```bash
npm install
npm run dev
```

CI builds it against every commit of the library, so it keeps working.
