Copy is an interaction. Treat it like one.

Headless React primitives for the whole clipboard moment: copying, pasting, coordinated groups and SVG capture. Honest errors, no flicker, accessible by default.

$ npm install react-smart-copy

Zero dependencies, about 3.4 kB for useCopy, safe to server-render, typed end to end, and 100% test coverage enforced in CI. Latest release v1.3.0.

Control Ctrl/⌘+C, not just your buttons

              

                Most copying is select-and-copy, which normally bypasses your app. useCopyInterceptor
                rewrites, redacts or blocks it inside one element. It writes through the copy event, so there is
                no permission prompt and it works over plain HTTP.
              

              

                Select from the first paragraph down into the credentials: exactly one scope handles a selection,
                the highest priority first, and it receives the whole selection. A transform that
                throws blocks the copy, so a redaction bug never leaks.
              

              

                
const { ref } = useCopyInterceptor<HTMLElement>({
  transform: ({ text }) => `${text}\n\nSource: ${location.href}`,
});

<article ref={ref}>…</article>

// Redact, and win overlapping selections
useCopyInterceptor({ priority: 10, transform: mask });

// Block: return false
useCopyInterceptor({ transform: () => false });

              

              
This prevents accidents, not determined users: screenshots and dev tools still work.

    Quick start
    
          
    
            One component gives you a real button named "Copy Email", reveal on
            hover, focus and touch, a screen-reader announcement, ignored
            double-clicks, and a return to idle after two seconds.
          
    
          
    
            
    import { CopyField } from 'react-smart-copy';

export function ContactRow() {
  return (
    <CopyField.Root value="shubh@example.com" label="Email" className="group row">
      <CopyField.Label />
      <CopyField.Value />
      <CopyField.Trigger className="opacity-0 group-data-[revealed]:opacity-100 focus-visible:opacity-100" />
    </CopyField.Root>
  );
}
    
          
    
          
    Prefer your own markup? Use the hook. copy() never rejects; it resolves to an outcome you can branch on.
    
          
    
            
    import { useCopy, useDisplayStatus } from 'react-smart-copy';

function InvoiceNumber({ id }: { id: string }) {
  const { copy, status } = useCopy();
  const shown = useDisplayStatus(status);

  return (
    <button type="button" onClick={() => void copy(id)}>
      {shown === 'copied' ? 'Copied' : 'Copy'}
    </button>
  );
}
    
          
    
        
    
        
    
          
    Pasting
    
          
    
            Three paths: a button that calls paste() (may prompt for permission),
            targetProps.onPaste for keyboard paste, and dropTargetProps for
            drag-and-drop. The last two need no prompt, because the data arrives in the event, and
            all three go through the same accept, limits and image checks.
          
    
          
    
            
    import { usePaste } from 'react-smart-copy';

function PasteZone() {
  const { paste, targetProps, dropTargetProps, isDragOver, status, result } = usePaste({
    accept: ['text/plain', 'image/png'],
  });

  return (
    <>
      <button type="button" onClick={() => void paste()}>
        {status === 'reading' ? 'Reading…' : 'Paste'}
      </button>
      <div {...targetProps} {...dropTargetProps} tabIndex={0} data-over={isDragOver || undefined}>
        Drop here, or Ctrl+V
      </div>
      {result?.text && <pre>{result.text}</pre>}
    </>
  );
}
    
          
    
        
    
        
    
          
    PasteField
    
          
    
            The paste-side companion to CopyField. One component gives you
            a labelled zone, a trigger button, a live-region announcement, and the same
            reveal-on-hover behaviour as CopyField.
          
    
          
    
            
    import { PasteField } from 'react-smart-copy';

export function NotesPasteField({ onNotes }: { onNotes: (text: string) => void }) {
  return (
    <PasteField.Root
      label="Notes"
      pasteOptions={{ accept: ['text', 'image'], onPaste: (result) => onNotes(result.text ?? '') }}
    >
      <PasteField.Label />
      <PasteField.Zone>Paste here…</PasteField.Zone>
      <PasteField.Status />
      <PasteField.Trigger />
      <PasteField.Preview placeholder="Nothing pasted yet" />
    </PasteField.Root>
  );
}
    
          
    
          
    
            Styling: data-display-state on Root, Zone and Trigger; data-revealed
            on Root and Trigger when hover or focus makes the button visible; data-drag-over
            on the Zone while an accepted drag is over it (droppable={false} turns drops off).
            Override messages to internationalise the built-in strings.
            PasteField.Preview shows pasted text, image thumbnails and file names,
            and never renders pasted HTML.
          
    
        
    
        
    
          
    Retry and cancellation
    
          
    
            When the Paste button fails for a reason that can pass (permission denied, page not
            focused), retry() reads again, up to maxRetries, and
            canRetry says whether it can help. Every copy and paste also carries an
            AbortSignal that fires on reset(), on unmount, or when a newer
            operation takes over, so slow captures and large decodes stop instead of running on.
            onCancel(reason) tells you when that happens, with 'reset',
            'disconnect' or, for paste, 'superseded'; onReset()
            runs after reset() clears a result.
          
    
          
    
            
    const { paste, retry, canRetry } = usePaste({
  accept: ['image'],
  onCancel: (reason) => analytics.track('paste_cancelled', { reason }),
});

// Image sources and custom adapters receive the signal:
copy({ kind: 'image', blob: (context) => renderChart(context?.signal) });
    
          
    
        
    
        
    
          
    Copy groups
    
          
    Wrap a table or list in <CopyGroup> and only one row shows "Copied" at a time. Copying another row resets the previous one immediately.
    
          
    
            
    import { CopyGroup, CopyField } from 'react-smart-copy';

function ContactCard({ contact }) {
  return (
    <CopyGroup>
      <CopyField.Root value={contact.name}  label="Name"  ><CopyField.Trigger /></CopyField.Root>
      <CopyField.Root value={contact.email} label="Email" ><CopyField.Trigger /></CopyField.Root>
      <CopyField.Root value={contact.phone} label="Phone" ><CopyField.Trigger /></CopyField.Root>
    </CopyGroup>
  );
}
    
          
    
        
    
        
    
          
    Controlling native copy
    
          
    
            useCopyInterceptor decides what reaches the clipboard when someone selects text inside an element
            and presses Ctrl/⌘+C, Ctrl/⌘+X or uses the context menu. Return a string or payload to write instead,
            false to block, or nothing to leave the browser alone. Try it in the playground.
          
    
          
    
            
    import { useCopyInterceptor } from 'react-smart-copy';

function Credentials({ children }) {
  const { ref } = useCopyInterceptor<HTMLDivElement>({
    priority: 10, // wins selections that also touch other scopes
    transform: ({ fragment, text }) => {
      if (!fragment) return '[redacted]'; // inside an <input>
      fragment.querySelectorAll('[data-redact]').forEach((n) => (n.textContent = '••••'));
      const box = document.createElement('div');
      box.append(fragment);
      return { kind: 'html', html: box.innerHTML, text: box.textContent };
    },
    onError: (error) => report(error), // the copy is blocked: fails closed
  });
  return <div ref={ref}>{children}</div>;
}
    
          
    
          
    
            Writes go through the copy event, so there is no permission prompt and no HTTPS requirement. Only strings
            can be written that way: the types reject image payloads and async transforms. Cuts in inputs and
            editable regions still remove the selection, with undo intact. When several scopes overlap, one handles the
            selection: highest priority, then innermost, then first in the page. Without React, use
            registerCopyInterceptor(element, options) from react-smart-copy/core.
          
    
          
    It stops accidental leaks, not determined users: screenshots and dev tools still work.
    
        
    

        
    
          
    Capturing SVG and UI
    
          
    
            react-smart-copy/capture turns an <svg> into a verified PNG with
            no extra dependency. For any other element, bring your own rasteriser. Capture starts inside
            the click and stops if the copy is reset or the component unmounts.
          
    
          
    
            
    import { captureImage, svgToPngBlob } from 'react-smart-copy/capture';
import { useCopy } from 'react-smart-copy';

const { copy } = useCopy();

// An SVG chart, rasterised by the library:
copy({ kind: 'image', blob: (context) => svgToPngBlob(chartRef.current, { signal: context?.signal }) });

// Any element, with a rasteriser such as html2canvas:
copy(captureImage(() => cardRef.current, {
  rasterize: (node) => html2canvas(node),
}));
    
          
    
        
    
        
    
          
    Payloads
    
          
    
            A bare string is text. Everything else is a discriminated union, so
            TypeScript stops you from copying HTML without a plain-text
            fallback, or an image from a URL.
          
    
          
    
            
    copy('PLT-29018');
copy({ kind: 'html', html: '<b>INV-29018</b>', text: 'INV-29018' });
copy({ kind: 'json', value: customer, pretty: true });
copy({ kind: 'image', blob: () => chartToPngBlob() }); // runs inside the click
copy(() => editor.getValue());                          // read at click time
    
          
    
        
    
        
    
          
    What it supports, honestly
    
          
    
            This library only promises what browsers actually support.
            Everything else is a typed error, never a silent success.
          
    
          
    
            
    
              
                
    
                  Content
                  Support
                  Notes
                
    
                  
              
                
    
                  Plain text
                  Copy + Paste
                  Everywhere the async Clipboard API exists.
                
    
                
    
                  Rich HTML
                  Copy + Paste
                  Copy always paired with a required plain-text fallback.
                
    
                
    
                  Images
                  PNG
                  
                    Copy writes image/png. Paste images are byte-verified before acceptance; pasted image files also arrive in result.imageFiles with their names, ready for FormData.
                  
                
    
                
    
                  JSON
                  Copy
                  Serialised to text; JSON isn't a native clipboard format.
                
    
                
    
                  Several formats at once
                  Copy
                  kind: 'multi', each type checked with ClipboardItem.supports().
                
    
                
    
                  SVG / DOM element as image
                  Capture
                  react-smart-copy/capture — rasterizes to PNG, no extra dep for SVG.
                
    
                
    
                  Files (PDF, DOCX, ZIP)
                  No
                  No browser API can put files on the system clipboard.
                
    
                
    
                  Plain HTTP pages
                  No
                  The Clipboard API needs HTTPS or localhost. You get insecure-context.
                
    
                  
            
    
          
    
        
    
        
    
          
    No flicker, by design
    
          
    
            A text copy takes one to five milliseconds. Render that state
            directly and "Copying…" flashes for a single frame while the button
            resizes. Try the carbon sheet at the top of the page: the real state passes through
            copying, but for a fast copy you are never shown it.
          
    
          
    
            
    
              
    status
    
              
    The real, instantaneous state. Use it for logic, analytics and tests.
    
            
    
            
    
              
    displayStatus
    
              
    
                What to render. "Copying…" appears only after 150 ms, then
                stays at least 400 ms, so it can't blink.
              
    
            
    
            
    
              
    Stable width
    
              
    The default label stacks every state in one grid cell, so the button never changes size.
    
            
    
          
    
        
    
        
    
          
    When it fails, you know why
    
          
    
            error.message is for developers. Show users
            describeCopyError(error), or map
            error.type through your own translations.

    Accessible without extra work
    
          
    
            
    
              
    A real button
    
              
    Reachable with Tab, activated with Enter or Space, with a stable name like "Copy Email".
    
            
    
            
    
              
    Announced results
    
              
    A live region, mounted before its first message, says "Copied to clipboard" or explains the error.
    
            
    
            
    
              
    Focus never jumps
    
              
    The trigger is never disabled mid-copy, because disabling a focused button throws focus back to the page.
    
            
    
            
    
              
    Hidden, not removed
    
              
    Revealed actions stay in the tab order. On devices that can't hover, they're always visible.
    
            
    
          
    
        
    
        
    
          
    Next.js and server rendering
    
          
    
            The React entry ships with "use client", so it imports
            cleanly from Server Components. Nothing touches window
            during render, so server and client agree and hydration never mismatches.
            react-smart-copy/core is framework-agnostic; this page runs on it with plain JavaScript.
          
    
        
    
        
    
          
    API at a glance
    
          
    
            
    
              
                
    
                  Export
                  Entry
                  What it is
                
    
                  
              
                
    
                  CopyField.Root / .Label / .Value / .Trigger
                  default
                  Full compound component with reveal, announcement and retry built in.
                
    
                
    
                  CopyGroup
                  default
                  Wraps fields — only one shows "Copied" at a time, via React context.
                
    
                
    
                  useCopy(options?)
                  default
                  { state, status, error, canRetry, copy, retry, reset } — all stable.
                
    
                
    
                  usePaste<T>(options)
                  default
                  { status, result, error, canRetry, paste, pasteEvent, dropEvent, retry, reset, targetProps, dropTargetProps, isDragOver }
                
    
                
    
                  PasteField.Root / .Label / .Status / .Zone / .Trigger / .Preview
                  default
                  Compound paste component: labelled zone, trigger, safe preview, reveal and announcements built in.
                
    
                
    
                  usePasteField()
                  default
                  Access field state from a custom sub-component. Must be inside <PasteField.Root>.
                
    
                
    
                  useDisplayStatus(status)
                  default
                  The flicker-free status for rendering — delays "copying", holds it for minPendingMs.
                
    
                
    
                  useRevealOnInteraction()
                  default
                  Hover, keyboard focus and touch reveal for any row of actions.
                
    
                
    
                  useCopyInterceptor<T>(options)
                  default
                  { ref } — rewrite, redact or block native Ctrl/⌘+C and cut inside the element.
                
    
                
    
                  createCopyMachine()
                  /core
                  Framework-agnostic state machine — subscribe/snapshot pattern.
                
    
                
    
                  createPasteMachine()
                  /core
                  Same shape as copy machine. paste() and pasteEvent(event).
                
    
                
    
                  createCopyCoordinator()
                  /core
                  activate / deactivate / getActive — powers CopyGroup.
                
    
                
    
                  registerCopyInterceptor(element, options)
                  /core
                  Framework-agnostic native copy interception. Returns an unsubscribe function.
                
    
                
    
                  svgToPngBlob(source, options?)
                  /capture
                  SVG element or markup string → PNG Blob. No external dependency.
                
    
                
    
                  captureElement(node, options)
                  /capture
                  DOM element → PNG Blob via caller-supplied rasteriser.
                
    
                
    
                  captureImage(getNode, options?)
                  /capture
                  Returns a { kind: 'image', blob } payload ready for copy().
                
    
                  
            
    
          
    
          
    
            Styling hooks on Root and Trigger: data-display-state,
            data-state and data-revealed. Works with
            Tailwind, CSS modules, CSS-in-JS, shadcn, MUI and Ant Design.
