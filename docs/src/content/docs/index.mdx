```bash
npm install react-smart-copy
```

```tsx
import { CopyField } from 'react-smart-copy';

export function ContactRow() {
  return (
    <CopyField.Root value="shubh@example.com" label="Email">
      <CopyField.Label />
      <CopyField.Value />
      <CopyField.Trigger>
        {({ displayStatus }) =>
          displayStatus === 'copied' ? 'Copied' : displayStatus === 'error' ? 'Retry' : 'Copy'}
      </CopyField.Trigger>
    </CopyField.Root>
  );
}
```

## Why it is different

<CardGrid>
  <Card title="Honest errors" icon="warning">
    Every failure is a typed, classified error: permission denied, insecure page, too large, not
    supported. Nothing silently no-ops.
  </Card>
  <Card title="Accessible by default" icon="approve-check">
    Screen-reader announcements, focus and keyboard handling built in, and checked with axe in
    Chromium, Firefox and WebKit.
  </Card>
  <Card title="Small and headless" icon="puzzle">
    About 3.5 kB for `useCopy`, no runtime dependencies, and no styles: it fits Tailwind, CSS
    modules, shadcn, MUI or your own design system.
  </Card>
  <Card title="Safe everywhere" icon="seti:lock">
    Server-render safe, React 18 and 19, StrictMode-proof. Pasted HTML is parsed inert, and pasted
    photos lose the location they were taken at.
  </Card>
</CardGrid>
