Read plain text from the clipboard, by button or keyboard.

Pasted text appears here.

Two ways in, one state machine

The button calls paste(), which may ask for permission. Keyboard paste needs no permission: the data is already in the event. If the button is blocked, retry() appears, because that failure can pass.

const { paste, retry, canRetry, targetProps } = usePaste();

<button onClick={() => void paste()}>Paste</button>
{canRetry && <button onClick={() => void retry()}>Try again</button>}
<textarea {...targetProps} />
