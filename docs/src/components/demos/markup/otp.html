Codes without the busywork

extractOtp finds the code in an SMS or an e-mail, in a dozen languages and any script's digits, and leaves prices, dates, times, phone numbers and order numbers alone.

useOtpField wires a row of boxes for typing, pasting, SMS autofill on iOS and Android, and the WebOTP API, with an accessible name on every box. 

import { useOtpField } from 'react-smart-copy';

const otp = useOtpField({ length: 6, onComplete: verify });

<div role="group" aria-label="Verification code">
  {Array.from({ length: 6 }, (_, index) => (
    <input key={index} {...otp.getInputProps(index)} />
  ))}
</div>
