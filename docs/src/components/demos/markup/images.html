    Nothing leaves with the photo

    Phone photos carry where they were taken, the device and an embedded preview. prepareImage removes all of it. When only the metadata has to go, no pixel is touched.

    For limits, it searches for the highest quality that fits before it makes the image smaller. Sizes are read from the header and checked before decoding, so a hostile file can't exhaust memory. 

    import { prepareImage } from 'react-smart-copy/image';

usePaste({ accept: ['image'], onPaste: async ({ imageFiles }) => {
  const image = await prepareImage(imageFiles[0], {
    maxWidth: 2048, maxBytes: 1_000_000,
  });
  upload(image.file);
} });
