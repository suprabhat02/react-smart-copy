                Most copying is select-and-copy, which normally bypasses your app. useCopyInterceptor
                rewrites, redacts or blocks it inside one element. It writes through the copy event, so there is
                no permission prompt and it works over plain HTTP.
              

              

                Select from the first paragraph down into the credentials: exactly one scope handles a selection,
                the highest priority first, and it receives the whole selection. A transform that
                throws blocks the copy, so a redaction bug never leaks.
              

              

                
const { ref } = useCopyInterceptor<HTMLElement>({
  transform: ({ text }) => `${text}\n\nSource: ${location.href}`,
});

<article ref={ref}>…</article>

// Redact, and win overlapping selections
useCopyInterceptor({ priority: 10, transform: mask });

// Block: return false
useCopyInterceptor({ transform: () => false });
