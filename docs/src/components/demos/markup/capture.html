A live SVG chart, copied as a PNG image.

SVG to PNG, no extra dependency

svgToPngBlob rasterises inside the click so Safari keeps the gesture, enforces pixel and time limits, and stops when the copy is cancelled.

import { svgToPngBlob } from 'react-smart-copy/capture';

copy({
  kind: 'image',
  blob: (context) => svgToPngBlob(chartRef.current, { signal: context?.signal }),
});
