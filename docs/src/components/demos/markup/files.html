      The name says PDF. The bytes decide.

      acceptFiles reads the first 8 KB of each file and knows over 50 formats by their signatures, so an HTML page named invoice.pdf, a program named invoice.pdf.exe and a name that hides its real extension behind a right-to-left character are all turned away, each with a reason.

      Folders are walked within your limits on count, size and depth, names are made safe for every operating system, and each accepted file comes back ready to upload, with its real type. 

      import { acceptFiles } from 'react-smart-copy/files';

<div onDrop={(event) => {
  event.preventDefault();
  void acceptFiles(event, { accept: '.pdf,image/*', digest: true })
    .then(({ accepted, rejected }) => {
      for (const file of accepted) upload(file.upload);
      for (const file of rejected) toast(file.message);
    });
}} />
