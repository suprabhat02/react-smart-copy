The colour, in the code's format

colorPayload copies a colour as hex, rgb(), hsl(), oklch() or Display P3, with a swatch for Docs and Slack. Wide-gamut colours are mapped the way CSS specifies, keeping their hue.

pasteAsColor takes any CSS colour, even a declaration copied from developer tools, and inserts it in the field's format. contrastRatio is the WCAG 2 ratio, never rounded up. 

import { colorPayload, contrastRatio, pasteAsColor } from 'react-smart-copy/color';

copy(() => colorPayload(token.value, { format: 'oklch' }));

<input onPaste={(event) => pasteAsColor(event, { format: 'hex' })} />

contrastRatio('#767676', '#fff'); // 4.54
