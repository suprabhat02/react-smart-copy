The link, not just a URL

linkPayload copies a titled link and the URL, so chat and documents paste the title and editors paste the address. Dragged, it adds text/uri-list. Only safe schemes are copied, credentials never, and tracking parameters are removed when you ask.

useShare opens the share sheet on phones and copies the link on desktop. Closing the share sheet is never an error, and method tells the button what to say.

selectionLink links to the words the reader selected. pasteAsLink turns selected text into a link when a URL is pasted over it. 

import { linkPayload, pasteAsLink, selectionLink } from 'react-smart-copy/link';

copy(() => linkPayload({ url, title }, { clean: true }));

const link = selectionLink();
if (link) copy(() => linkPayload(link));
