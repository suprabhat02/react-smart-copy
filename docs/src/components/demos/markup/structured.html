    clipPayload writes the cards three ways: a web custom format, a custom clipboard type and a hidden envelope in the HTML. The paste button, Ctrl + V and drops each read a different one, so every path in every browser finds the cards.

    Whatever is pasted is checked before your code sees it: size-limited, parsed without prototype keys, migrated from older versions, then validated. "Copy a tampered clip" writes the same format with bad data, the way a buggy or hostile app could. 

    import { clipAccept, clipPayload, defineClipFormat, readClip } from 'react-smart-copy/structured';

const Cards = defineClipFormat({
  id: 'acme.cards',
  version: 2,
  schema: z.array(Card), // or Valibot, ArkType, a function
  migrate: { 1: (cards) => addTags(cards) },
});

copy(() => clipPayload(Cards, selected));

usePaste({ accept: clipAccept(Cards), onPaste: async (result) => {
  const clip = await readClip(result, Cards);
  if (clip.status === 'ok') addToBacklog(clip.value);
} });
