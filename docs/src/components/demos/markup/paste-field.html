Zone, trigger, status and preview

PasteField.Zone takes Ctrl/⌘+V and drops through the same checks; only drags it accepts get the drop cursor, and data-drag-over marks them. PasteField.Preview shows text, image thumbnails and file names, never pasted HTML. Image URLs are released when the result changes. Clear calls reset(), which also cancels a read in flight.
