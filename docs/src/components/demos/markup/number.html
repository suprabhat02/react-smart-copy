parseNumber reads 1.234,50 €, $1,234.50, lakh grouping, accounting brackets and any script's digits, and turns away dates, phone numbers and wrong grouping. exact keeps every digit, so money never picks up float errors.

pasteAsNumber puts the number in a field the way it takes it, and formatNumber writes it back for any locale. 

import { pasteAsNumber } from 'react-smart-copy/number';

<input
  type="number"
  onPaste={(event) => pasteAsNumber(event, { locale: 'de-DE' })}
/>
