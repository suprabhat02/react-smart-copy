Spreadsheet-ready, both ways

tablePayload puts an HTML table and tab-separated text on the clipboard together, so rows land as cells in Excel, Sheets and Numbers, and as a table in Docs or Notion. Amounts stay numbers, the PO numbers keep their leading zeros, and the formula in the third client name is neutralised.

Pasting reads Excel and Sheets HTML, including merged cells and line breaks, or falls back to the text. Adapters cover AG Grid, TanStack Table and any rendered <table>. 

import { fromAgGrid, fromRows, parseTable, tablePayload } from 'react-smart-copy/table';

copy(() => tablePayload(fromRows(invoices, [
  { header: 'Invoice', value: 'id' },
  { header: 'Amount', value: 'amount' },
])));

copy(() => tablePayload(fromAgGrid(api, { rows: 'selected' })));

usePaste({ accept: ['html', 'text'], onPaste: (result) => {
  const table = parseTable(result, { headers: true });
} });
