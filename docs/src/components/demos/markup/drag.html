Populate DataTransfer on drag

useDragCopy makes any element draggable and writes structured data into the DataTransfer when the user starts dragging — no Clipboard API, no permission prompt.

The source callback is called synchronously on dragstart and can return a string, a text / html / json / multi payload, false to cancel the drag, or null to leave the browser's default data untouched. 

const { ref, status } = useDragCopy({
  source: () => ({
    kind: 'html',
    html: '<b>Hello</b>',
    text: 'Hello',
  }),
  effectAllowed: 'copy',
});
return <div ref={ref}>Drag me</div>;

// Framework-agnostic:
import { registerDragCopy } from 'react-smart-copy/core';
const { unsubscribe } = registerDragCopy(el, () => ({
  source: () => text,
}));
