    The code, not the page around it

    codePayload copies the commands of a session without prompts or output, leaves out line numbers and buttons, and adds monospaced HTML with the block's colours for Docs and Slack.

    pasteAsCode fixes curly quotes and invisible characters, indents to the cursor and keeps undo. It reports bidi overrides (Trojan Source), invisible identifiers and lookalike letters, so a paste never runs differently from how it reads. 

    import { codePayload, pasteAsCode } from 'react-smart-copy/code';

copy(() => codePayload(preRef.current));

<textarea onPaste={(event) => pasteAsCode(event, {
  onPaste: (result) => !result.danger || confirm('Paste anyway?'),
})} />
