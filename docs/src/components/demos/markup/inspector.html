      What a paste really holds

      Apps put several formats on the clipboard at once: text/html, text/plain, sometimes text/rtf, files or private ones. The browser hands a page those formats in a paste event, and only there: navigator.clipboard.read() filters and rewrites them. This page reads the event with nothing but the browser's own API, so what it shows is what your handlers get.
