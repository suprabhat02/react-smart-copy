One handler on the textarea

pasteAsMarkdown converts rich pastes and inserts the Markdown at the cursor. Undo still works, your state updates as if the user typed it, and plain-text pastes are left alone: they are usually Markdown already.

Pasted HTML is parsed without running or fetching anything, the output never contains raw HTML, and links keep only safe URL schemes. Images become their alt text unless you opt in. 

import { htmlToMarkdown, pasteAsMarkdown } from 'react-smart-copy/markdown';

<textarea value={body} onChange={…} onPaste={pasteAsMarkdown} />

// Copy a rendered article as Markdown:
copy(() => htmlToMarkdown(articleRef.current).markdown);
